릴리안 윙이 발표한 LLM 기반의 자율 에이전트 중에서

### 1. 에이전트의 4가지 핵심 요소

- 계획: 에이전트는 복잡한 작업을 효율적으로 수행하기 위한 계획 능력과 의사 결정 능력이 필요.
    - 작은 목표로 분할 - subgoal decomposition
    - 사고의 연쇄 - chain of thought
    - 자기 성찰과 비판 - self-critics
    - 과거 행동에 대한 성찰 - reflection
- 기억 memory
    - 단기 기억: 맥락 학습과 관련있는 프롬프트 엔지니어링의 일부
    - 장기 기억: 정보의 장기 저장 및 검색과 관련. 일반적으로 외부 벡트 스토리지와 빠른 검색 활용
- 도구 tool: 에이전트가 호출할 수 있는 다양한 도구(계산기, 코드 해석기, 검색 기능 등)
    - LLM은 사전학습이 완료되면 기본적으로 내부 능력과 지식의 한계가 해당 시점으로 고정되며 확장하기 어려운 특징이 있어 도구들이 필요.
- 실행 action: 계확과 기억을 바탕으로 구체적인 행동 실행
    - 외부 세계와 상호작용하거나 도구를 호출해 작업을 완료하는 것

### 구체적으로 LLM추론을 통해 도구를 호출하고 작업을 완료하는 흐름

Kwai Agents 프로젝트 에이전트 추론 흐름

- 작업 수신 task receiving: 에이전트는 먼저 프롬프트를 통해 요청, 외부 추가 지식, 인물 설정을 읽어 작업을 수신
- 기억 갱신 memory update: 에이전트는 특정 작업에 따라 시스템의 기억을 갱신하여 처리 과정에서 필요한 정보를 최신 상태로 유지
- 기억 검색 memory retrieval: 관련 정보를 검색하거나 필요한 경우 데이터를 잘라내어 효율적으로 처리
- 작업 계획 task play: LLM은 이전 단계에서 제공된 구조화된 도구, 기억, 요청 프롬프트를 바탕으로 작업 이름을 포함한 계획을 생성. 후속 단계와 작업 포함. 사용해야할 도구와 매개변수 설명
- 도구 실행 tool execution: **작업 계획** 모듈에서 작업 완료가 되면 순환이 종료되고 에이전트에게 알려 결론 생성. 그렇지 않으면 시스템은 지정된 도구를 호출하고 실행. LLM은 도구가 생성한 지정된 형식의 결과를 관찰 후 이를 작업 기억과 통합
- 결론 도출 concluding: 시스템은 최종 답변을 요약하고 작업 처리과정을 끝냄

### 2. 에이전트의 계획 및 의사 결정 능력

LLM이 에이전트에게 부여하는 계획과 의사 결정 능력은 중요.

계획: 복잡한 작업을 더 작고 관리하기 쉬운 하위 작업으로 분해하는 과정

연구자들이 제안한 계획 기술 : **작업 분해, 외부 계획기와 결함, 자기 성찰**

- 작업 분해
    - 사고의 연쇄 chain of thought, CoT: 모델이 단계별로 생각하도록 유도하는 프롬프트 기술.
        
        큰 작업을 작은 작업을 분해하고 자신의 사고 과정을 설명하게 할 수 있음
        
    - 사고의 나무 tree of thought, ToT: 각 단계에서 다양한 추론 가능성을 탐색해 트리 구조 형성.
        
        프롬프트나 투표를 통해 각 단계를 평가할 수 있음
        
    - 간단한 프롬프트, 특정 작업에 대한 명령, 직접 수동으로 분해하는 작업으로 가능

LLM+P: LLM이 문제를  PDDL(계획 문제 정의 언어)로 변환해 외부 계획기에 요청해 계획을 생성하고, 계획을 다시 자연어로 변환. 계획 단계는 외부 도구에 위탁, 로봇 설정에서 흔히 사용됨

- 자기 성찰
    - ReAct: 특정 작업의 행동과 언어 공간을 결합해 모델이 환경과 상호작용하고 추론 궤적을 생성할 수 있도록 함.
    - Reflection: 에이전트가 동적 기억과 자기 성찰 능력을 갖출 수 있도록 함. 에이전트는 과거의 행동을 회구하여 추론 능력을 향상시킬 수 있음
    - CoH chain of hindsight: LLM에게 일련의 피드백이 포함된 과거 출력을 보여주고 이를 바탕으로 자신을 출력을 개선하도록 권장.

**ReAct 기반 체계**

- 대표적인 에이전트 추론 기반 체계. 에이전트의 동적 성격과 적응성에 중점
- 에이전트는 이 체계에서 작업에 대해 추론할 수 있고 상황에 따라 스스로 행동하고 조정 가능
- 위의 순환적은 과정을 반복해 에이전트를 더 유연하게 바꾸고 강한 적응력을 부여
- 도구를 호출해 새로운 결과를 만들어 내고 이 과정에서 에이전트 능력 강화

### 3. 에이전트의 다양한 기억 기제

LLM이 기억을 형성하는 기제

- 사전학습을 통해 기억 형성
- 상황context와 상호작용
    - 상황 정보가 LLM의 기억과 충돌하는 정보를 포함하고 있다면 이상적으로는 LLM은 더 정확하고 상황에 맞는 응답을 생성하기 위해 상황 정보를 우선 고려
    - 지식 인식형 파인튜닝 knowledge-aware fine-tuning 과 같은 방법을 통해 LLM이 상황 정보와 기억된 지식을 선택적으로 사용하는 방법의 제어 가능성과 견고성을 강화
- 특정 작업에 맞게 파인튜닝을 통해 성능을 강화하는 방법
- 메모리 뱅크와 같은 외부 기억 시스템을 LLM에 통합해 성능을 강화
    - 동적 개성 이해 dynamic personality understanding
    - 이중 타워 밀집 검색 모델 dual tower dense retrieval model을 사용한 기억 검색 memory retrieval
    - 에빙하우스의 망각곡선을 활용한 기억 갱신 기제

### 4. 에이전트의 핵심 기술: 도구 호출

- 도구는 추가 데이터, 처리 능력, 전문 지식, 기타 자원을 제공해 더 복잡한 작업을 수행할 수 있게 도와줌
- 도구 호출은 에이전트의 중요한 기술이지만 해결해야할 과제가 남아있다
    - 에이전트는 다양한 유형의 도구를 이해하고 조작할 수 있어야 함.
        - 복잡한 인터페이스를 해석하고 다양한 데이터 형식을 이해하며 도구를 효과적으로 사용하는 방법을 배우는 것 포함
    - 적절한 시기에 적합 도구를 선택할 수 있어야 함
    - 여러 도구의 사용을 관리할 수 있어야 함.
        - 여러 에이전트가 여러 도구를 동시에 호출하고 이들 도구 간의 협력과 데이터 교환이 활발하게 이루어지도록 해야 함

### 5. 에이전트의 추론 엔진: ReAct 기반 체계

- 환경에서 정보 추출하고 미래 작업을 계획하고 과거 경험을 활용하고 도구를 호출하는 방법을 결정
- 복잡한 추론과 효과적인 행동을 할 수 있고 강력하면서도 유연
- 추론과 행동을 밀접하게 결합할 때, 단순한 결정 트리나 고정된 알고리즘에 의존하는 대신 정보처리, 의사결정, 행동 실행을 실시간으로 할 수 있는 종합적인 시스템을 사용
- 설계 철학: 동적이고 불확실한 환경에서 효과적인 의사 결정을 하려면 지속적인 학습, 적응, 추론을 행동으로 빠르게 전환하는 능력이 반드시 필요하다는 것
- 3단계 순환 과정
    - 사고thought: 다음 행동을 추론하는 과정. 현재 상황을 평가하고 가능한 행동 방안을 고려
    - 행동action: 행동 계획을 선택하는 과정. 사고의 결과에 따라 어떤 행동을 할지 결정
    - 관찰observation: 행동을 실행한 후 그 결과를 관찰하고 피드백을 수집하는 과정. 행동의 결과를 평가 후 다음 사고 방향에 영향을 미칠 수 있음
- LLM을 중심으로 하는 자율 에이전트의 작업 흐름
    - 작업: 에이전트의 출발점. 사용자 질의, 목표, 해결해야 할 특정 문제 등이 해당
    - LLM: 작업은 LLM에 입력되고 학습된 모델을 이용해 추론 진행. 작업을 이해하고 해결책을 생성하거나 다른 추론 활동 수행
    - 도구: LLM은 작업을 완료하는 데 도움이 되는 도구를 사용할 수 있음. API호출, 데이터베이스 조회 등이 포함
    - 행동: LLM의 추론 결과에 따라 행동을 취함. 환경과 직접 상호작용, 요청 발신, 물리적 장비 조작, 데이터 변경.
    - 환경: 행동은 환경에 영향을 주고, 환경은 이러한 행동에 대해 응답. 이 응답을 결과result라고 함. 작업의 완료, 새 데이터 지점, 다른 유형 출력이 될 수 있음
    - 결과: 에이전트는 행동의 결과를 다시 피드백으로 받음. 에이전트의 미래 결과에 영향을 줄 수 있음.
    - 목표 작업이 완전히 해결될 때까지 계속 학습하고 적응하는 과정
- ReAct 기반 에이전트 체계 특성
    - 적응성: 특정 알고리즘이나 기술에 의존하지 않음. 다양한 방법, 추론 전략, 실행 기제와 결합 가능
    - 상호 작용성: 지속적인 학습과 동적 지식 관리 지원. 환경과 상호작용하고 환경의 변화에 적응해 행동 최적화 가능
    - 자율성: 스스로 결정을 내릴 수 있고 상황에 따라 행동과 전략을 자율적으로 조정 가능
    - 기능성: 도구 호출을 통해 특정한 작업 수행 가능
