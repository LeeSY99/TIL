# 9장 - 자연어 전처리

우리가 일상생활에서 사용하는 언어 의미를 분석해 컴퓨터가 처리할 수 있도록 하는 과정

**용어들**

- 코퍼스(corpus) - 학습·평가용으로 수집·정제된 언어 자료의 집합(메타데이터/라이선스, 도메인·언어 균형, 중복 제거 등).
- 토큰(token) - 텍스트를 잘게 쪼갠 조각들로 모델이 다루는 최소 단위
- 토큰화(tokenization): 텍스트(코퍼스)를 토큰으로 분리하는 과정
    - 코퍼스는 정제됐다고 했는데? - 중복제거, 노이즈 제거, 대소문자 등 이런과정
- 불용어(stop words): 문장에서 많이 등장하는 단어. 자주 등장하기 때문에 분석과 관계가 없음
- 어간 추출(stemming): 접사/어미를 잘라 단어를 줄임
- 표제어 추출(lemmatization) : 품사/사전 지식을 이용해 사전에 있는 기본형으로 변환 → 사전에 없는 형태가 나올 수 있음
- 품사 태깅(part-of-speech tagging): 주어진 문장에서 품사를 식별하기 위해 붙이는 태그 → 의미, 품사 보존

**자연어 처리 과정**

인간의 자연어가 입력 텍스트로 들어옴 → 입력에 대한 전처리(tokenize → stop words 제거 → stemming → normalization) → 임베딩 → 모델을 이용해 분류 및 예측 수행

### **자연어 처리를 위한 라이브러리**

**NLTK**

주요 기능: 말뭉치, 토큰생성, 형태소 분석, 품사 태깅

**KoNLPy**

한국어 자연어 처리를 위한 파이썬 라이브러리

**Gensim** - 파이썬에서 제공하는 Word2Vec 라이브러리

**임베딩**: Word2Vec

**토픽 모델링**: 텍스트 본문의 굼겨진 의미 구조를 발견하는데 사용하는 텍스트 마이닝 기법

**LDA:** 각 문서에 어떤 주제들이 존재하는지 소술하는 확률적 토픽 모델 기법

사이킷런(scikit-learn)

**CountVectorizer**: 텍스트에서 단어의 등장 횟수를 기준으로 특성 추출

**Tfidfvectorizer**: TF-IDF값을 사용해 텍스트에서 특성을 추출

- TF(Term Frequency): 하나의 문서(문장)에서 특정 단어가 틍장하는 횟수
- IDF(Inverse Document Frequency)
    - DF - 특정 단어가 몇개의 문서(문장)에서 등장하는지 수치화
    - IDF → DF를 수식화(역수느낌)해서 적은 문서(문장)에 등장할수록 큰 값이 나옴 → 여러 문장에 의미없이 사용되는 단어의 가중치를 줄임

**HashingVectorizer**: CountVectorizer와 방식 동일하지만 해시함수를 이용해 시간 단축

### 전처리

1. 결측치 확인
    1. 데이터에 하나라도 결측치가 존재할 때 행 전체 삭제
    2. 데이터가 거의 없는 특성(열)은 특성(열) 자체를 삭제
    3. 최빈값/평균값으로 대체
2. 토큰화(tokenization)
    1. sent_tokenize: 문장 단위로 토큰
    2. word_tokenize: 단어 단위
    3. WordPunctTokenizer - 어포스트로피(’)가 포함된 문장에서 단어 토큰화
3. 불용어(stop word) 제거
    
    불용어는 자연어 처리에서 효율성을 감소시키고 처리시간이 길어지는 단점이 있어 제거해야 함
    
4. 어간 추출
    
    stemming
    
    porter, lancaster(랭커스터) - porter가 좀 더 의미를 보존시키고 lancaster가 과감하게 삭제
    
    lemmatization
    
    nltk.WordNetLemmatizer
    
5. 정규화
    
    데이터셋이 가진 특성(열)의 모든 데이터가 동일한 정도의 범위를 갖도록 하게 하는 것
    
    **MinMaxScaler**: 모든 칼럼이 0~1사이에 위치하도록 범위 지정
    
    이상치에 민감: 이상치가 있으면 좁은 범위로 압축되기 때문
    
    **StandardScaler**: 평균 0, 분산 1로 변경해 값을 조정
    
    **RobustScaler**: 중간값과 4분위수 범위(nterQuartile Range) → 좀 더 넓게 분포
    
    **MaxAbsScaler**: 절댓값이 0~1 사이가 되도록 조정. 즉 모든 데이터가 -1~1사이가 되도록 조정 → 이상치에 민감
